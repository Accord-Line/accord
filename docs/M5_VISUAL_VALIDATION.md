# 纸感工作空间：布局、文案与动效迭代

日期：2026-10-15。范围是本地应用的视觉与交互整理；不是 M5 全生命周期追踪功能全部完成的声明。原有 M4 领域模型、人工批准、历史回退、备份与交接仍保留。

## 任务与证据

任务句：产品负责人在同一份 PRD 中自由写需求、操作交互、审阅真实修改，并明确批准需要保留的版本。成功状态是正文与参数可恢复，审阅能看清变化，批准之前原版本不变。

已观察：用户截图中审阅页默认把整篇规范左右重复展示，窄屏阅读负担大。参考页面 https://vibe-design-labs.github.io/Vibe-UI-UX/ 已用实际浏览器读取并截图；参考其纸色、手写字、墨绿朱红与清楚的工作区布局。重写本应用的视觉样式、图标和文案；没有修改 IntentKit 原仓库。字体文件原样分发，来源与 SIL OFL 许可证位于 `public/fonts/`。

设计推断：减少默认重复内容、延后展示高级配置，会更容易识别下一步。缺失信息：尚无目标用户任务测试、操作用时或回访数据，不能据此宣称转化率、易用性或留存已经提高。

## 层级与组件规则

首屏阅读顺序：当前项目与保存状态 → 一句话任务 → 首块 AI 协作 → 单份可编辑规范。文案使用具体动作，避免在日常路径暴露协议细节。纸色 `#f4ecd9`、纸张 `#fffaf0`、正文 `#363e32`、墨绿 `#526047`、朱红 `#af432f`；标题用手写字体，正文 15–17px，图标 20–24px。这些是方案取值，不是无障碍合格声明。

同一规范驱动正文、体验、审阅与批准历史。只在明确批准后生成新版本。请求失败保留正文并显示补救提示；生成期间正文变化使候选过期；存储冲突停止写入，允许导出备份。主栏目切换回到顶部，避免停留在上一页中部。没有增加账号、官方代理、遥测或云端存储。

## 动效实现与边界

本机 Canvas 装饰层不拦截指针，最多保留 18 组效果，每组约 1.05 秒；只有活跃效果时绘制，屏幕像素比上限 1.5。鼠标移动与滚动节流；输入、正文阅读、弹层与代码区避开点击装饰；编辑器聚焦时不显示滚动水波。失焦、页面隐藏、停用和卸载清除效果与监听。右上角雨云按钮可暂停；系统减少动态偏好优先，真实交互预览也关闭位移动画。

- 完成主流程及失败/返回路径：自由编辑 → 保存 → 预览 → 参数体验 → 审阅 → 批准 → 导出 → 重新导入；同时检查拒绝、过期候选、401、429、断网、取消、恶意导入、双标签冲突、Key 清除和减少动态效果。
- 实际桌面走查截图：`m5-first-desktop.png`、`m5-first-split.png`、`m5-first-mobile.png`；模型设置 `m5-connection-*.png`；变化审阅 `m5-review-*.png`。三种尺寸均未发现横向溢出或浏览器脚本错误。
